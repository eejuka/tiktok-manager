A private content manager for your own TikTok videos.

TikTok Manager is a private content-management service. It lets the account owner organize TikTok videos, connect TikTok accounts through TikTok Login Kit, manage publishing, and review statistics that TikTok makes available.

The application runs on the operator’s own Windows computer. It is not a public social network, and it does not ask for a TikTok password. Account access uses TikTok’s official OAuth flow and the official Content Posting API.

What the service does

  • Keeps separate folders and settings for more than one TikTok account.
  • Detects video files that the operator places in those folders.
  • Publishes a video only after the operator confirms the post.
  • Requests statistics only when the operator asks for them.
